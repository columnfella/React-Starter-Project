# React Fun Facts

A static page presenting fun facts about React. This was my first React project, built to learn components, JSX and project setup with Vite.

## Features

- Navbar and main content split into reusable components
- Styled with plain CSS

## Tech stack

React · JavaScript · Vite

## Getting started

```bash
npm install
npm run dev
```
